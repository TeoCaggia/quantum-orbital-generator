# Desktop viewer

Complete user guides: [English](../../README.md) · [Italiano](../../README.it.md).

From the project directory, install PySide6 and start the viewer:

```powershell
python -m pip install -r files/requirements-viewer.txt
python files/orbital_viewer.py
```

To open an existing model directly:

```powershell
python files/orbital_viewer.py output/C.glb
```

The initial periodic table automatically opens `output/<Symbol>.glb` when available. The viewer supports local GLB and glTF models. A model generated by this project has matching metadata at `<model directory>/json/<model name>.json`; this file supplies electron occupations and element information to the interface.

Drag to rotate, use `Shift` + drag to pan, and use the mouse wheel to zoom. The right panels control orbital visibility and the left panels show element data, the Bohr diagram, and natural isotopic composition.
